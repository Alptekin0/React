# 🧩 TypeScript Practice

Bu proje, **TypeScript’in temel özelliklerini** örneklerle göstermek için hazırlanmıştır.  
`App.tsx` dosyasında değişken tipleri, union types, diziler ve fonksiyon tipleri gibi temel kavramlar gösterilmektedir.
<br /> <br />
## 📘 İçerik
- **Temel tip atamaları:** `string`, `number`, `boolean`
- **Union types:** (`string | number`, `"uygundur" | "uygun değildir"`)
- **Dizi tipleri:** `string[]`, `number[]`
- **Optional property kullanımı:** `yas?: number`
- **Fonksiyon tipi tanımlama:** `function sum(a: number, b: number): number`
