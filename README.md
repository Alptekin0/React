# React Örnekleri Reposu

Bu depo, **React öğrenme sürecimde** yaptığım çeşitli küçük projeleri içermektedir.  
Her klasör, React'in farklı bir özelliğini veya konusunu öğrenmek amacıyla hazırlanmış ayrı bir örnek projedir.

<br/>

## 📂 Proje Listesi

### 1. `axios-veriCekme`
**Axios** kullanarak API'den veri çekme ve bu verileri dinamik olarak ekranda gösterme örneği.

### 2. `e-ticaret`
Ürün listeleme, sepete ekleme ve **React Router** ile sayfa geçişleri içeren küçük bir **e-ticaret uygulaması**.

### 3. `react-book-app`
Kitap yönetim uygulaması — bileşen yapısı, props ve state yönetimi konularını pekiştirmek için oluşturulmuştur.

### 4. `todoList`
**useState** ve **useEffect** hook'larını kullanarak yapılmış klasik bir **yapılacaklar listesi uygulaması**.

### 5. `typeScript_calisma`
**React + TypeScript** yapısında hazırlanmış örnekler.  
Props, state ve fonksiyonel bileşenlerde tip tanımlama pratikleri içerir.
<br/> <br/>

## 🧰 Kullanılan Teknolojiler
- **React** (Vite)
- **JavaScript / TypeScript**
- **Axios**
- **React Router**
- **CSS Modules**

<br/> <br/>
## 📖 Amaç  
Bu depo, React öğrenme sürecimi belgelemek ve farklı konseptleri denemek için oluşturulmuştur.  
Her proje, yeni bir özelliği veya teknolojiyi öğrenme amacı taşır.
